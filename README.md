# 掼蛋 AI 竞技场

四个独立 AI 选手、服务端掼蛋裁判、Vue 3 + TypeScript + Vite、Three.js 角色、LangGraph 决策流水线，以及独立的直播观战页面。

## 启动与访问

需要 Node.js 22 或更新版本。项目根目录运行以下命令：

```sh
npm ci
npm run dev
```

`npm run dev` 会同时启动 API 服务和 Vite 前端：API 默认监听 `3001`，前端默认监听 `5173`。等终端分别显示 API 已启动和 Vite 的 `Local` / `Network` 地址后再访问。首次启动会创建 `data/admin.json`；仅在该文件首次创建时，初始化账号为 `ymtadmin`、初始口令为 `ymthcx3344520`。已有 `data/admin.json` 时继续使用原账号密码，不会重置。这个初始口令是项目内置默认值；只在可信局域网运行，不要把开发服务或默认凭证暴露到公网。

本机浏览器打开 `http://127.0.0.1:5173/login`。手机或另一台电脑访问时：

1. 确保设备连接到运行项目电脑所在的可信局域网；访客 Wi-Fi、设备隔离网络可能禁止互访。
2. 在运行项目的 Windows 电脑执行 `ipconfig`，找到正在使用的 Wi-Fi 或以太网适配器的 `IPv4 地址`，例如 `192.168.1.23`。也可直接使用 Vite 终端打印的 `Network` 地址。
3. 在手机浏览器打开 `http://192.168.1.23:5173/login`，把示例 IP 替换成电脑的实际 IPv4 地址。观众使用工作室生成的 `/watch/<分享标识>` 地址。

不要把 `0.0.0.0` 当作浏览器网址；它只表示服务监听所有网卡。前端的 `/api` 请求会由 Vite 转发到本机 API，因此手机只需访问前端显示的地址，不需要直接访问 `3001`。`.env` 中的 `HOST` 默认应为 `0.0.0.0`；如果改了 API `PORT`，Vite 代理会读取同一个值。

如果手机打不开页面，先确认电脑和手机在同一局域网，再打开“Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙”，只允许 Node.js 在“专用网络”通信；也可以仅对专用网络放行开发端口 `5173/TCP`。不要在公共网络放行，也不要配置路由器公网端口转发。端口被占用时 Vite 会改用终端提示的其他端口，请以实际打印的 `Network` 地址为准。

### 生产模式

生产模式由 Express 在同一端口提供构建后的前端和 API：

```sh
npm ci
npm run build
npm start
```

默认端口为 `3001`，在局域网设备访问 `http://<运行项目电脑的IPv4>:3001/login`。`.env` 可配置 `HOST` 和 `PORT`；局域网访问时 `HOST=0.0.0.0`，并在防火墙仅对可信专用网络开放实际服务端口。若使用 Coolify，保持仓库根目录为构建上下文、`deploy/Dockerfile` 为 Dockerfile，容器端口 `3001`。

常用检查命令：`npm test` 运行测试，`npm run build` 执行前后端类型检查并构建生产前端。`.env` 为本机私有配置，不要用 `.env.example` 覆盖已有 `.env`；模型 Key 可在管理员界面配置，服务端环境变量仅作为兼容方式。

## 管理与分享

- `/login`：管理员登录；`/studio`：管理工作室；`/arena`：管理员对局控制。
- 管理员从直播工作台复制 `/watch/<分享标识>`，或在对局页点击“分享观战”。观众不需要登录，只能观战。
- 观众不能访问管理 API、配置或其他三家手牌。管理员使用 HttpOnly Cookie 会话，旧 CONTROL_TOKEN 已停用。
- 手机自动使用竖屏取景、贴近角色的名称卡片和扇形手牌；显式竖屏可追加 `?layout=portrait`。
- 管理员可以暂停、开始、重新开始。重开立即重新发牌，旧模型返回的动作不会污染新局。

## 模型与 JEV

在模型配置页直接填写 Base URL、模型 ID 和 API Key。保存后不回显 Key，留空保留，填写新值替换，勾选删除清除。配置在后端加密保存，凭证不进入观众状态、前端存储或录像。旧环境变量仅作为现有部署的兼容路径，新配置不需要新增环境变量。

当前使用 `https://model.rhzy.ai/v1`，四个座位分别为桃桃 / MiniMax-M3、蓝莓 / kimi-k2、团子 / glm-5.3-flash、芒果 / gpt-5.6-luna。首次无模型配置时使用四个内置策略。

JEV 是四个选手自主调用的 MCP 辅助工具，不能替代任何选手。模型仅得到自己的手牌、公开局势和合法候选；工具咨询后仍由该模型选择，裁判校验动作。当前 JEV 地址为 `http://10.0.10.2:8019/mcp`，部署服务器必须具有相应内网路由。

## 解说与直播

直播画面会自动展示大牌特写、烟花、机器人震惊与庆祝、贡牌往返仪式和局末领奖舞台。胜方跳舞、败方哭泣，结算显示真实升级结果；支持手机竖屏与系统减少动态偏好。[演出说明与验收记录](docs/broadcast-effects.md)。

解说开关及动态面板由服务器广播同步。控制台静音，观众页播放；观众首次点击开启声音以满足浏览器播放限制。

已统一为服务器生成真实音频、观众通过 HTML 音频组件播放，不再依赖浏览器系统语音或选择解说方式。默认自然普通话女声，无需语音 Key；需重新构建镜像安装 Python 与 edge-tts，并保证服务器可访问在线语音服务。点击开启会播放有声欢迎提示，只有播放成功才进入已开启状态。播放固定正常倍速、牌面转换为中文口播；真实微信／QQ／手机浏览器仍需部署后验收。

OBS 可采集分享页；抖音、快手、视频号使用各自官方直播工具与授权账号。本项目提供画面和解说，不会自行完成平台授权或开播。禁止赌博声明常驻观战画面。
