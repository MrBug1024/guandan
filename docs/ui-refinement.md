# 本地界面精细化

采用 ui-ux-pro-max 的界面层级、响应式布局、焦点状态与可读性建议，结合现有 Three.js 场景实现。配色统一为深海军蓝、玉绿和暖金；保留四位机器人各自的识别色。大厅、模型配置、直播工作台、手牌回放、登录和对局界面共享控件与间距规范，窄屏工作室使用底部导航。

观看视角提供四个座位的第一视角及全桌第三视角。控制台统一选择镜头，对局和直播页面通过 SSE 实时跟随，不展示独立视角选择器；状态仅发送当前所选座位的手牌。第三视角展示整桌，并保留当前所选座位的观战手牌。回放页面不展示独立视角选择器。

验证：生产构建和 34 项测试通过，新增 HTTP 座位校验、SSE 座位推送与镜头模式检查。浏览器检查了登录、四个工作室页面、全部五种镜头；390px 窄屏检查了大厅及手牌回放，并修正大厅插画遮挡。未进行手机整场对局验收。

经本地预览确认后，提交界面优化与控制台统一切换视角的最终实现。
