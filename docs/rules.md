# arena-v3 规则约定

当前实现一套明确规则，不声称覆盖所有地方变体。基础参考：项目附带的长江商学院讲座（图片型培训材料），以及 [东南大学公开的双副牌掼蛋比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)、[南京邮电大学游戏 AI 竞赛说明](https://gameai.njupt.edu.cn/gameaicompetition/gameGD/index.html)。讲座中未逐页提取所有细则，以下以代码及测试定义为准。

## 发牌与牌型

四个座位按 0→1→2→3 顺时针，对家 0/2、1/3 组队。双副 108 张，27 张／人。第一局 0 号先手；洗牌使用 Node crypto 无偏随机交换。

普通点数 2 < 3 < … < A < 当前级牌 < 小王 < 大王。红桃级牌单出仍是级牌；可替代任意非王牌组成合法牌型，不可替代大小王。

| 牌型             | 固定张数／限制                 | 比较               |
| ---------------- | ------------------------------ | ------------------ |
| 单张、对子、三张 | 1、2、3 张同点                 | 点数（含级牌提高） |
| 三带二           | 三张同点 + 另一点数对子        | 三张点数           |
| 顺子             | 恰好五张连续点数               | 顺子顶点数         |
| 三连对           | 恰好三组连续对子               | 连对顶点数         |
| 钢板             | 恰好两组连续三张               | 钢板顶点数         |
| 同点炸弹         | 4–10 张同点，含红桃级牌替代    | 先张数再点数       |
| 同花顺           | 同一花色的五张顺子，允许逢人配 | 顶点数             |
| 四王             | 两大王 + 两小王                | 最大               |

连续牌型使用牌面点数，级牌在顺子里不提高。A 可作最小或最大，不可绕过 K-A-2 相连。顺子范围 A2345 到 10JQKA；三连对可 AA2233 到 QQKKAA；钢板可 AAA222 到 KKKAAA。

炸弹顺序：四王 > 10/9/8/7/6 张炸弹 > 同花顺 > 五张炸弹 > 四张炸弹 > 普通牌型。普通牌型只可同型压制。未出完的玩家可不出；自由领出不能不出。

## 接风与名次

一次有效出牌后，其余仍在场的玩家都不出，出牌者重新领出。若出牌者已出完，优先由尚未出完的对家接风；对家也出完则下一个在场玩家领出。

同队包揽头游、二游时立即双下结算，另外两人共同标记“双下”，不人为判断谁是三游、末游；否则打完三人的牌后，剩余玩家为末游，本局结束。头游队获胜：对家二游升三级，三游升两级，末游升一级。按当前所打级牌加级，封顶 A；不降低胜方已经取得的更高等级（例如已有 A 级的队伍在打 5 的一局获胜仍保留 A）。本副确实打 A、胜方自身等级也是 A，且对家为二游或三游，则比赛结束；头游但对家末游仍需重打 A。本桌启用「三次尝试不过 A 降回 2」：按选择本副级牌的队伍（上一局头游方）记录其打 A 尝试，头游但队友末游或未拿头游都算失败；第三次失败降至 2，重置失败计数。各队分别累计自身连续失败的 A 尝试，不把另一队的尝试计入；成功过 A 后比赛结束。该规则属于本桌地方约定。

## 贡还牌

下局打上局胜方升级后的等级。上局双下（第三、第四同队）执行双贡，否则末游向头游单贡。

进贡牌为手中除红桃级牌外最大的牌。单贡者持两大王抗贡；双贡两人合计持两大王抗贡。抗贡后头游先出。

双贡较大的贡牌给头游，另一张给二游；相同贡牌按头游之后顺时针遇到的贡方优先分配，头游之后的下一座先出（与上局两个输家的先后排序无关）。非相同贡牌由进贡较大牌者先出。单贡由末游先出。

还贡选天然点数 10 以下（含 10）、非红桃级牌的最小牌；没有符合牌时选非红桃级牌中的最小牌。所有贡还交换基于发牌后同时计算，避免刚收到贡牌被立刻还回。

## 决策空间

引擎按目标牌型生成合法解释，包含自然牌与红桃级牌各种数量分配。等价复制牌和普通组合中的等价花色按稳定 ID 选取，避免巨量重复动作；同花顺单独按花色生成。外部模型候选最多 41 条，并保留启发式首选与不出；这意味着外部模型并非每步搜索全部可能动作。

“无 10 及以下可还时返最小牌”的边界补充参考[华南农业大学公开竞赛规则](https://xgh.scau.edu.cn/_upload/article/files/cb/dc/a3903c0746239ff0ac31b8f5b343/e48c50d8-d766-45ee-9c9b-7605f74b71e8.pdf)。相同双贡分配与过 A 条件在不同竞赛规程间有差异，本项目使用上文明确约定，未把不同版本混称为统一国家标准。

## 观战中的规则过程

结算显示头游与队友名次、升级级数与前后等级，以及过 A 成功／失败次数／降级。单贡、双贡和抗贡使用结构化事件传给观众，仅公开交换牌，不公开其他手牌。开局有 4 秒贡还展示期，期间不请求模型决策；显示实际贡牌、还牌、方向及先手。接风提示由真实领出权变更触发，不使用随机定时动画。裁判进贡提示及结算结果进入解说队列，回放逐步状态记录这些信息。

页面“本桌规则”说明出牌方向、固定首局先手、A 的使用、还贡无合格牌时的边界处理及过 A 地方约定，避免把本桌约定误认为各地统一规则。
