# 直播演出升级

直播观战、管理对局和回放共用同一套演出。演出依据服务器公开牌局状态触发。

| 牌局事件                     | 画面与角色表现                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------- |
| 四王、同花顺、六张及以上炸弹 | 牌面逐张翻入特写、主题光环、烟花；出牌方庆祝、搭档鼓掌、对手震惊                 |
| 普通炸弹、炸弹反压           | 金色牌面特写；反压提升到强演出                                                   |
| 顺子、连对、钢板、大小王     | 较短的牌型特写，跟随出牌节奏                                                     |
| 头游、其他选手出完           | 收官提示、庆祝动作与彩纸                                                         |
| 首次进入剩余三张以内         | 冲刺提示；对手担忧、搭档鼓掌                                                     |
| 接风                         | 展示队友接风领出                                                                 |
| 单贡、双贡                   | 4 秒贡牌仪式，分进贡、接贡、还贡三个阶段，公开交换的牌在双方之间移动             |
| 抗贡                         | 双王护盾与抗贡成功提示，进贡方得意、对方惊讶                                     |
| 局末                         | 自动切到领奖舞台；胜方在中央跳舞，败方面向观众哭泣，结算卡显示真实升级结果与排名 |
| 成功过 A                     | 冠军奖杯和本场冠军结算                                                           |

大牌演出约 2.8–3.2 秒，轻提示约 1.8–2.2 秒。局末庆祝与自动续局统一为 10 秒，冠军烟花为 12 秒，时间定义共用 `shared/broadcast-timing.ts`。烟花采用升空拖尾、双层绽放和多轮彩纸，结算持续 18 轮烟花；桌面同时最多 1100 个粒子，手机最多 650 个。新出牌会更新特写，不出牌期间保留当前有效特写。下一局仍由服务器控制。局末舞台随结算状态保留，进入下一局时恢复原观战视角。

选手身份改为固定的队伍信息区：桌面分列在两侧下方，手机排在牌桌与观战手牌之间。按对家关系分组，以对应机器人外形的小头像连接角色与身份，展示姓名、位置、剩余牌数、思考或行动状态、完赛名次；当前行动席位有地面光环，手牌标题也使用同一头像。信息区不跟随角色动作，局末让位给领奖舞台。表情提示移到头顶，窄屏领奖时只保留胜方欢呼提示，败方保留哭泣动作。统一提高比分、姓名、牌数、结算与控制按钮的字号和文字对比，桌面“禁止赌博”为 23px，手机为 17px。

设计参考：[LCS 官方 HUD 改版](https://lolesports.com/en-US/news/summer-broadcast-updates-the-hud)关于固定信息位置、关键数据层级和姓名可读性的说明；[Valve 观战界面](https://blog.counter-strike.net/2012/08/4839/)把双方选手身份与实时状态放在统一信息区的做法。具体双人队伍、机器人头像与手机布局为本项目设计。

机器人采用更饱满的头部和爪子比例，脸颊为连续曲面，眼睛使用光泽材质与两处高光；软质外壳、奶油色口鼻、绒感耳内、金属天线与胸前电源徽章分别使用对应材质。桃桃有尖耳、卷尾，蓝莓有长耳、绒球尾巴，团子与芒果有圆耳、短尾。眨眼采用错开的间隔与平滑开合，呼吸与耳朵回弹幅度保持轻微；开心切换弯曲笑眼，惊讶切换张大的眼睛与圆口，难过配合眉毛与泪滴。头像同步调整比例与眼睛高光。角色复用球体几何和材质，卸载时按资源去重释放；减少动态时保留静态表情，停止眨眼、呼吸和耳尾摆动。第一视角根据窗口比例保持两侧角色完整，桌面近景提示与规则入口放在上方中央空白区。

重复 SSE 状态不会重播烟花；中途进入直播不庆祝历史出牌。重开、换局、回放倒退会清除旧演出。结算优先于最后一手的大牌。结算展示服务器的 `from`、`to`、`upgrade` 和过 A 状态，失败次数归属于打 A 方。

尊重系统“减少动态效果”，且支持在页面打开期间切换：关闭烟花、光环、跳舞和眼泪循环，保留牌型、结算、贡牌信息与静态表情。Canvas 烟花限制粒子数和像素比，结束、切换事件、页面隐藏及卸载时释放动画；3D 表情与舞台几何在初始化时创建并复用。

验收：构建、45 项测试通过；隔离服务验证 10 秒结算倒计时、暂停取消续局和自动开下一局。使用公开牌局模拟验收特写、烟花、升级与冠军结算、贡牌仪式、第一视角和动态偏好切换；选手信息区检查了 375×812、820×700、844×390、1074×884 和 1280×720。烟花与结算截图使用模拟牌局，`docs/screenshots/broadcast-player-roster.jpg` 来自实际直播；实际模型出牌仍由原裁判流程决定。

机器人造型另检查手机牌桌与领奖、桌面第一视角、大牌惊讶与笑眼、减少动态切换和实际管理牌桌。`broadcast-robots-closeup.jpg`、`broadcast-robots-celebration.jpg` 为模拟牌局展示，`broadcast-robots-table.jpg` 为实际牌桌。领奖时角色按舞台高度落脚，避免脚掌陷入台面；近景检查 1074×884 与 1280×720，运行时无控制台错误。本次全套测试有一次隔离服务启动超时，单独重跑该文件的 2 项测试均通过，其余 43 项已在全套中通过。

关键文件：`src/arena-events.ts` 选择事件和角色表情；`src/useArenaShow.ts` 管理事件寿命与动态偏好；`src/ArenaShow.vue` 绘制特写、烟花和反应；`src/ArenaCeremony.vue` 展示贡牌和结算；`src/arena-robot.ts` 创建角色模型、材质和表情组件；`src/ArenaScene.vue` 提供角色动作、泪滴与领奖舞台；`src/ArenaRoster.vue` 与 `src/RobotPortrait.vue` 展示选手身份和实时状态。
