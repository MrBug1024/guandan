# 管理员登录、只读分享、移动观战与解说更新

此文档替代旧的控制口令部署说明。代码需同时更新前端与后端。

## 部署 AI 更新步骤

1. 暂停对局，备份当前代码版本、服务环境变量和完整 `data/`。
2. 更新 GitHub `master`。Coolify 保持仓库根目录为构建上下文，Dockerfile 为 `deploy/Dockerfile`，端口 3001；按现有流程重新构建部署。
3. **保留 `/app/data` 持久化卷及写权限**。新增 `data/admin.json` 保存密码哈希、分享标识和配置加密密钥；`data/agents.json` 保存加密配置。二者必须成对备份和恢复，不能只复制 agents.json 或删除 admin.json。
4. 现有模型配置及环境变量仍兼容；无需重新填写旧 Key。管理员保存新配置后，配置文件使用 AES-256-GCM 加密。新 Key 可直接在界面填写，不需要新增环境变量。
5. `CONTROL_TOKEN` 已停用，可以移除；不能再使用它调用管理 API。所有管理 API 使用登录产生的 HttpOnly 会话 Cookie。
6. HTTPS 反向代理需保留 Host、X-Forwarded-Proto；代码信任一层代理。不能在反向代理前再增加多层非受控代理。SSE `/api/events` 关闭响应缓冲、允许长连接。`/api/health` 保持公开用于健康检查。
7. 新容器启动后管理员会话失效，需要重新登录。默认账号为 `ymtadmin`，初始密码按项目负责人此次指定值初始化；不要把密码或 Key 写入部署日志。
8. 清理前端旧缓存，检查 `/login`、工作室和手机观战页。

非容器方式可在项目目录执行 `git pull --ff-only origin master`、`npm ci`、`npm test`、`npm run build`，再使用原有进程管理器重启 `npm start`。

## 管理员与观众

- 管理员登录 `/login` 后进入 `/studio`，管理模型、直播和回放。
- 工作室“直播工作台”提供 `/watch/<分享标识>` 链接；管理对局页也有“分享观战”。分享页无需登录，隐藏所有管理操作。
- 手机自动进入竖屏布局；宽屏维持完整牌桌。手牌以真人握牌式扇形排列，非滚动列表。手机镜头独立调整距离和角度。
- 非管理员访问工作室、模型配置、回放或 `/arena` 会进入登录页；即使自行调用 API，管理请求也返回 401。分享链接仅允许读取观战状态和解说音频，不允许控制比赛或读取其余三家手牌。
- 分享标识会随管理员数据持久化，管理员退出登录不影响观众链接。

## Key 管理

模型和 JEV Key 填写到各自的密码输入框。保存后不回显，只显示“已配置”；留空保留，输入新值替换，勾选“保存时删除”清除对应 Key 并解除旧环境变量引用。凭证不进入公共状态、SSE、前端存储或导出录像。

JEV 仍是四个选手自主调用的辅助工具。服务器能否访问 `http://10.0.10.2:8019/mcp` 必须由部署端确认，不可用本地网络连通性代替。

## 微信与手机声音

网页音频通常需要用户点击才能获得浏览器播放许可。声音不需要申请麦克风、相机或定位；这些权限不能解决播放限制。[浏览器自动播放规则](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)解释了这个机制。

解说统一使用真实音频播放，不再依赖浏览器 speechSynthesis。默认音色改为 `zh-CN-XiaoxiaoNeural` 普通话女声，语速 `-8%`，播放固定 `1×`。口播独立于可视牌面，J/Q/K/A 读作“勾／圈／凯／尖”，花色读中文，对子、三带二等用简洁中文说明，不逐张朗读重复牌面。连续播报排队播放，最多保留三条待播，不能通过加速追赶直播。

**必须重新构建 deploy/Dockerfile 镜像**，不能只更新 dist。镜像加入 Python 隔离环境 `/opt/voice` 与 `edge-tts==7.2.8`，无需额外 Key。服务器通过社区 edge-tts 客户端访问 Edge 在线语音服务（不是微软官方 SDK）；仅发送解说文本，服务可用性取决于服务器出网。默认不再使用 eSpeak，在线音色失败时提示重试，不静默变成机械音色。旧版已配置的 TTS 接口仍兼容，失败后尝试新的默认音色。

非 Docker Linux 安装：`apt-get install -y python3 python3-venv ca-certificates`，`python3 -m venv /opt/voice`，`/opt/voice/bin/pip install edge-tts==7.2.8`。开发环境可在项目内创建 `tmp/voice-venv` 并安装同一版本；自定义解释器路径可使用 `NARRATION_PYTHON`，此变量不含凭证。

部署 AI 验收：在运行容器内执行 `/opt/voice/bin/python -m edge_tts --voice zh-CN-XiaoxiaoNeural --rate=-8% --text "桃桃打出一对三。" --write-media /tmp/voice-check.mp3`，确认生成 MP3；遇到失败检查服务器到在线语音服务的 HTTPS/WebSocket 出网，不能改回 eSpeak 后宣称恢复自然解说。保留原 data 卷。观众点击开启后，应听到自然中文欢迎提示；仅播放成功才显示开启。

真实手机验收：微信、QQ、系统浏览器分别点击开启，听欢迎提示及后续播报，确认语速正常、没有英文牌面读法；关闭解说立即停止。本地已真实生成自然中文 MP3并验证欢迎音频接口和缓存；未在真实手机或 Linux 生产容器验收。OBS 需开启音频捕获。

## 重开比赛

管理员点击“重新开始”会立即结束当前内存比赛、重新发牌并启动新比赛。正在返回的旧模型结果被代际标识丢弃，不能影响新比赛；新比赛调度不等待旧模型请求返回。旧请求可能仍由服务商完成，但其结果不会采用。观众页面通过 SSE 同步新比赛。

## 验收清单

1. 默认管理员登录、错误密码拒绝、退出后管理 API 拒绝访问。
2. 在无登录 Cookie 的另一台设备打开分享链接，只能观战；试图进入工作室需要登录。
3. 设置模型/JEV Key，保存后刷新看不到原值；验证留空保留、替换、删除。
4. 在 390×844、375×667、手机横屏和桌面检查牌桌、四位选手、扇形手牌与安全区，确认没有横向页面溢出或信息覆盖。
5. 在真实微信内点击开启声音。确认有声欢迎提示及后续真实音频播报；关闭解说后声音立即停止。
6. 控制页开启／关闭动态面板，观众页同步显示／隐藏。
7. 在模型思考期间重开比赛，观众出现新手牌，旧动作不会补入新局。
8. 真实检查四模型、JEV、完整结算和自动续局。前次 GLM 线上连接未通过，需继续排查。

本地验证：29 项测试涵盖登录权限、只读分享、哈希密码、加密配置、Key 删除／保留、中文口播转换、TTS 音频缓存及思考期间重开后丢弃旧决策；生产构建通过。真实微信与生产部署后的验收不能用本地测试代替。

## 回滚

如需回退到不支持加密配置的旧代码，必须一起恢复更新前的配置备份；旧代码不能解析新加密文件。新版本间回滚也应保持 admin.json 与 agents.json 配套。不要丢弃数据卷来“修复”登录或配置问题。
